# FAST-LIO2: Fast Direct LiDAR-inertial Odometry

该论文提出的FAST-LIO2，是一种基于高效紧耦合迭代卡尔曼滤波器的，快速、鲁棒且通用的激光雷达-惯性导航里程计框架。

FAST-LIO2实现了快速、鲁棒且精确的激光雷达惯性导航及建图，它提出了两个关键创新点。第一个创新是直接将原始点云配准到地图中，并随后更新地图（建图），而无需进行特征提取，这使得配准能够利用环境中细微的特征，从而提高精度，同时，省去了人工设计特征提取模块的麻烦，更使其天然适用于不同扫描模式的新型激光雷达（因为人工设计特征提取模块需要考虑到不同类型激光雷达产生的点云特点）；第二个主要创新是采用增量式k-d树数据结构ikd-Tree来维护地图，该数据结构支持增量更新（即点的插入和删除）和动态再平衡，相比于现有的动态数据结构（八叉树、R*-树、nanoflann k-d树）相比，ikd-Tree的整体性能上表现更优。

总体而言，FAST-LIO2具备高效的计算性能（例如，在大型室外环境中可实现高达100 Hz的里程计与建图）、良好的鲁棒性（例如，在杂乱的室内环境中即使旋转速度高达1000 deg/s仍能可靠估计位姿）以及广泛的适用性（即可用于多线旋转式和固态激光雷达、无人机及手持平台，以及基于Intel和ARM的处理器），同时仍能比现有方法达到更高的精度。

高效且精确的激光雷达里程计与建图仍然是具有挑战性的问题：

-   当前的激光雷达每秒钟能够产生数十万到数百万个三维点，在实时处理和有限的机载计算资源下处理如此大量的数据，要求Lidar里程计方法具有很高的计算效率；
-   为了降低计算负载，通常会基于局部平滑度提取特征点，例如边缘点和平面点。但是特征提取模块容易受到环境的影响（例如，在缺乏大平面和长边缘的非结构化场景中，特征提取的特征点数量可能极少，如果激光雷达的视场角比较小，可用的匹配点对数将更少）；此外，特征提取还因激光雷达的不同而有所差异，具体取决于扫描方式（如旋转式，基于棱镜，基于MEMS，以及点云密度），因此采用特征提取的激光雷达里程计方法通常需要大量的手工设计工作；
