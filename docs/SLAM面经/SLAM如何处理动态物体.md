# SLAM如何处理动态物体

关于如何SLAM如何处理动态物体，可以把脉络概括成一句话：早期 SLAM 把动态物体和遮挡当“外点”删掉；后来开始用语义、运动、多传感器把它们识别出来；再往后，系统不只维护静态地图，还显式建模“会动的物体、会变化的环境、被遮挡但仍存在的区域”。

1.静态世界假设+鲁棒估计：把动态当噪声处理

经典SLAM默认环境刚性静止，动态点通常通过RANSAC、鲁棒核、重投影误差、ICP残差、光流不一致等方式剔除。优点是工程简单，能直接应用到ORB-SLAM、LSD-SLAM、LOAM、Cartographer这类框架里；缺点是当动态物体占画面大比例或长期遮挡时，静态特征不够，系统容易漂移或者跟丢，这个阶段的本质是“保相机位姿，牺牲动态信息”。
