# General, Single-shot, Target-less, and Automatic LiDAR-Camera Extrinsic Calibration Toolbox



本论文提出了一种开源的lidar-cam外参标定的工具箱，该工具箱适用于各种lidar和cam投影模型，仅需一对无需标定目标的lidar和cam数据，即可完成lidar和cam的外参标定，且整个过程完全自动化。

为了实现自动化的外参初值估计，我们采用SuperGlue图像匹配流程来寻找lidar与相机数据之间的2D-3D对应关系，并通过随机挑选3对点对，利用RANSAC来挑选出合理阈值内的所有匹配点对，以估计lidar-cam的外参变换。在获得初始估计后，利用基于归一化信息距离的直接lidar-cam配准方法进一步优化外参估计结果。为便于标定操作，我们还提供了若干辅助功能（例如动态lidar数据融合以及用于手动建立2D-3D对应关系的可视化用户界面）。

实验结果表面，所提出的工具箱能够实现旋转式与非重复扫描lidar、针孔及全向相机任意组合的标定，并在标定精度与鲁棒性方面优于当前最先进的基于边缘对齐的标定方法。

## 标定流程

如下图所示，首先要获取稠密点云和图像构成一组数据，对于旋转式激光雷达，可以通过SLAM等方式累积多帧来获取稠密点云，对于非重复扫描激光雷达，可以静置不动进行重复扫描采集获取稠密点云。

获取到稠密点云之后，我们将稠密点云投影为矩形柱面图，像素值为每个点的反射强度值，类似于灰度图，然后我们通过SuperGlue进行点云柱面图和camera img的特征匹配，由于点云柱面图上一个像素点对应一个3D点坐标，所以就可以获取2D-3D对应点匹配关系。然后通过2D-3D对应点匹配关系，可以求解出lidar和cam的初始外参。这一步也可以通过手动拖拽完成。

由于SuperGlue可能存在误匹配，尤其是点云柱面图与camera img这种跨模态的场景下，为了尽量避免错误点对干扰初始外参的估计，我们通过RANSAC算法来剔除错误匹配点对，具体来说，每次迭代，我们随机挑选3个点对，进行SVD求解初始外参，然后把点云投影到图像上，计算和图像匹配点的投影误差，只有投影误差在给定阈值内的点才被计为内点，算法经过多次迭代后保留内点数最多的外参，这就直接剔除了大量明显错误的匹配。另外，在后续的非线性最小二乘优化中，代码为代价函数特意添加了柯西核函数（Cauchy Loss）。即使有少部分 RANSAC 漏网的误匹配点参与了优化计算，它们产生的巨大残差也会被柯西核函数强力衰减，从而避免将整个外参带偏。

在得到粗略旋转后，代码使用 Ceres Solver 构建了一个最小二乘问题。它将待优化外参作为李群 `Sophus::SE3d`（包含平移与旋转，共6个自由度）放置在流形空间上进行更新迭代。优化的目标函数 `ReprojectionCost` 就是为了最小化 3D LiDAR 点投影回 2D 相机平面后产生的像素级**重投影误差**。

进入标定的核心——**精细标定阶段（Visual Camera Calibration）时，工具完全抛弃了所有由 SuperGlue 生成的局部特征匹配点对**。它改用基于全局信息统计的“直接法”：计算真实的相机图像像素值分布与重投影过来的 LiDAR 点云强度分布之间的**归一化信息距离（Normalized Information Distance, NID）**。随后使用 Nelder-Mead（无导数优化）或 BFGS 算法直接寻找让全局互信息最大、NID 最小的 `SE3` 位姿变换，这彻底避免了局部特征提取误差带来的上限问题。
