# FAST-LIO2框架源码学习

## 整体代码架构与核心目录

核心源码主要集中在 `src` 目录下，主要分为以下几个核心模块：

-   **`laserMapping.cpp`**：主程序入口。负责 ROS 节点初始化、传感器数据订阅（回调函数）、多线程调度以及整个系统的核心主循环。
-   **`IMU_Processing.hpp`**：IMU 处理模块。负责 IMU 的正向传播（Forward Propagation）以及点云的后向传播运动畸变补偿（Backward Propagation）。
-   **`preprocess.cpp` / `preprocess.h`**：点云预处理模块。由于 FAST-LIO2 是直接法（Direct Method），它去除了传统的特征提取模块 ，所以这里主要进行盲区过滤、降采样以及针对不同雷达（如 Livox 固态雷达或传统机械旋转雷达）的格式统一。
-   **`ikd-Tree/` 文件夹**：增量式 k-d 树模块 。这是 FAST-LIO2 效率极高的核心，支持增量更新和动态重平衡 。
-   **`IKFOM/` 文件夹**：基于流形的迭代卡尔曼滤波库 。这是一个通用的数学工具箱，FAST-LIO2 的状态估算完全依赖于它。
