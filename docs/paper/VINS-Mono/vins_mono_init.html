为何单目 VIO 必须初始化

VINS-Mono 是一个紧耦合的单目 + IMU 系统。两类传感器各有"先天缺陷",必须在后端非线性优化(滑动窗口 BA)开始前,先求出一组靠谱的初始值,否则优化极易陷入局部极小或直接发散。

未知量原因
尺度 (scale) $s$单目相机无法恢复绝对尺度,SfM 得到的平移只是"相差一个比例因子"的相对值。
重力方向 $g$IMU 加速度计测量值中混入了重力,必须先知道重力在初始相机系下的方向,才能把它从加速度中扣除。
陀螺仪零偏 $b_g$陀螺仪存在缓变偏置,直接积分会导致姿态漂移。
每帧速度 $v$紧耦合优化需要速度作为状态量的初值。

加速度计零偏 $b_a$ 在初始化阶段通常不单独标定:它与重力高度耦合(都体现在加速度里),且初始时刻数据短、激励弱,强行估计反而不稳,因此 VINS-Mono 将其初值设为 0,留给后端优化慢慢收敛。

💡 核心思想:先用纯视觉求出可靠的相对位姿(SfM),再用 IMU 预积分把视觉信息"对齐"到带尺度、带重力的物理世界。 这就是所谓的"视觉惯性对齐 (Visual-Inertial Alignment)"。

① 纯视觉 SfM(Structure from Motion)

初始化第一步完全不用 IMU,只靠图像恢复一个局部、无尺度的相机位姿与三维点云。

关键步骤

  1. 选参考帧:在滑动窗口中找一帧与最新帧之间,既有足够视差(parallax)又有足够多匹配特征点的帧。视差不够说明相机几乎没动,无法稳定三角化。
  2. 求相对位姿:对这两帧用对极几何 / 五点法求本质矩阵 $E$,分解得到相对旋转 $R$ 与平移方向 $t$(平移只有方向、模长归一,这就是"无尺度"的来源)。
  3. 三角化:用这两帧位姿三角化出初始路标点。
  4. PnP 扩展:对窗口内其余帧,用已有 3D 点做 PnP 求位姿,再三角化更多点。
  5. 全局 BA:对整个窗口做一次纯视觉 Bundle Adjustment,联合优化所有相机位姿与路标点,得到一致的局部地图。
⚠️ 此时所有平移量都带有一个未知公共尺度因子 $s$,即真实平移 $= s \times$ SfM平移。SfM 也无法感知重力。后续步骤的任务就是借 IMU 补上 $s$ 和 $g$。

注:SfM 得到的旋转 $R^{c_0}_{c_k}$ 是相对准确的(尺度不影响旋转),这是下一步标定陀螺仪零偏的关键约束来源。

② IMU 预积分(Pre-integration)

IMU 输出频率(几百 Hz)远高于相机(几十 Hz)。若每次优化都重新积分两帧间所有 IMU 数据,代价太大。预积分把两关键帧 $b_k \to b_{k+1}$ 之间的 IMU 测量预先积成三个增量,且写成只与零偏相关、与绝对位姿/重力无关的形式。

$$\alpha_{b_{k+1}}^{b_k} = \iint_{t\in[k,k+1]} R_t^{b_k}(\hat a_t - b_a)\,dt^2,\quad \beta_{b_{k+1}}^{b_k} = \int_{t\in[k,k+1]} R_t^{b_k}(\hat a_t - b_a)\,dt$$ $$\gamma_{b_{k+1}}^{b_k} = \int_{t\in[k,k+1]} \tfrac{1}{2}\,\Omega(\hat\omega_t - b_g)\,\gamma_t\,dt$$

分别是位置增量 $\alpha$、速度增量 $\beta$ 和旋转增量 $\gamma$(四元数)。它们在参考系 $b_k$ 下定义,因此与世界系的重力、初始速度解耦。

✅ 预积分量只依赖 IMU 原始测量和零偏 $b_g, b_a$。当零偏发生小变化时,可用一阶雅可比直接线性修正,无需重新积分——这正是它在初始化与后端中被反复使用的原因。

由 IMU 运动学,相邻帧的世界系状态满足以下关系(后续对齐方程的基础):

$$p_{b_{k+1}}^w = p_{b_k}^w + v_{b_k}^w \Delta t - \tfrac{1}{2}g^w \Delta t^2 + R_{b_k}^w \alpha_{b_{k+1}}^{b_k}$$ $$v_{b_{k+1}}^w = v_{b_k}^w - g^w \Delta t + R_{b_k}^w \beta_{b_{k+1}}^{b_k}$$

③ 陀螺仪零偏标定

视觉 SfM 给出的相邻帧旋转 $q_{b_k}^{c_0}$、$q_{b_{k+1}}^{c_0}$ 是较准确的;而 IMU 预积分旋转增量 $\gamma_{b_{k+1}}^{b_k}$ 中含有零偏误差。两者本应一致,据此构造约束:

$$\min_{\delta b_g} \sum_{k\in B} \left\| \,\gamma_{b_{k+1}}^{b_k}{}^{-1} \otimes (q_{b_k}^{c_0})^{-1} \otimes q_{b_{k+1}}^{c_0} \,\right\|^2$$

理想情况下括号内的相对旋转应为单位四元数(虚部为 0)。把 $\gamma$ 关于零偏做一阶展开 $\gamma_{b_{k+1}}^{b_k} \approx \hat\gamma_{b_{k+1}}^{b_k} \otimes \begin{bmatrix}1 \\[2pt] \tfrac12 J_{b_g}\,\delta b_g\end{bmatrix}$,令虚部为零,得到关于 $\delta b_g$ 的 $3\times 3$ 线性最小二乘正规方程,直接求解:

$$\big(J^\top J\big)\,\delta b_g = J^\top \, b$$

求得 $\delta b_g$ 后更新 $b_g$,再用一阶雅可比重新传播(repropagate)所有预积分量 $\alpha,\beta,\gamma$。此阶段假设 $b_a$ 暂为 0。

④ 速度、重力与尺度初始化(线性对齐)

这是初始化的核心。利用第②步的运动学方程,把待求量拼成一个大向量,构造线性最小二乘一次性求解。待求状态:

$$\mathcal{X}_I = \big[\, v_{b_0}^{b_0},\; v_{b_1}^{b_1},\; \cdots,\; v_{b_n}^{b_n},\; g^{c_0},\; s \,\big]^\top$$

其中每帧速度在各自的 body 系下表示,$g^{c_0}$ 是初始相机系下的重力向量,$s$ 是把 SfM 平移变成真实尺度的因子。把运动学方程中的 $p_{b_k}^w$ 用 SfM 位姿($s\,\bar p^{c_0}_{c_k}$ 与外参 $p_c^b$)代入并整理,得到对每对相邻帧成立的线性观测:

$$\hat z_{b_{k+1}}^{b_k} = \begin{bmatrix} \alpha_{b_{k+1}}^{b_k} - p_c^b + R_{c_0}^{b_k}R_{b_{k+1}}^{c_0}p_c^b \\[4pt] \beta_{b_{k+1}}^{b_k} \end{bmatrix} = H_{b_{k+1}}^{b_k}\,\mathcal{X}_I + \text{noise}$$

其中 $H$ 是只含已知量(预积分、SfM 旋转、$\Delta t$、外参)的系数矩阵。把窗口内所有相邻帧的观测堆叠成 $H\mathcal{X}_I = z$,解正规方程:

$$\mathcal{X}_I = \big(H^\top H\big)^{-1} H^\top z$$
✅ 关键洞察:重力把绝对尺度"焊"进了方程。 加速度计同时测到重力($\approx 9.81$)与运动加速度,只要轨迹有足够运动激励,$g$ 的已知模长就成了"标尺",从而让单目缺失的尺度 $s$ 变得可观测。这也是为什么初始化时必须有充分的平移激励(不能纯旋转/静止)。

⑤ 重力向量细化

第④步把 $g^{c_0}$ 当成自由的 3 维向量来解,但其模长其实是已知常数 $|g| = 9.81\,\text{m/s}^2$。直接解出的 $g$ 模长通常略有偏差。细化做法是固定模长、只优化方向——这是一个 2 自由度问题。

把重力参数化为 $g = |g|\,\hat{\bar g} + w_1 b_1 + w_2 b_2$,其中 $\hat{\bar g}$ 是当前重力方向单位向量,$b_1,b_2$ 是其切平面上的两个正交基,$w_1,w_2$ 是待求的 2 维扰动:

$$g \leftarrow |g|\,\hat{\bar g} + b_1 w_1 + b_2 w_2$$

用这个 2 维参数化替换第④步方程中的 $g$,重新构建并求解线性系统,得到 $w_1,w_2$ 后更新 $\hat{\bar g}$ 并归一化。迭代数次直到收敛。这样既保证 $|g|$ 守恒,又把待求维度从 3 降到 2,数值更稳。

⑥ 恢复世界系并启动优化

此时已得到初始相机系 $c_0$ 下的重力 $g^{c_0}$、尺度 $s$、各帧速度与零偏。最后一步是把整个系统对齐到重力对齐的世界系 $w$(z 轴竖直向上):

  1. 计算把 $g^{c_0}$ 旋转到世界系 $z$ 轴 $[0,0,1]$ 的旋转 $R^{w}_{c_0}$(绕水平轴旋转,yaw 不可观测,设为 0)。
  2. 用 $R^{w}_{c_0}$ 把所有位姿、速度、重力从 $c_0$ 系转到 $w$ 系。
  3. 用尺度 $s$ 把所有平移量乘上,恢复带公制单位(米)的真实轨迹。
  4. 用估到的速度、$b_g$($b_a=0$)填充滑动窗口状态。
🎯 初始化完成!系统拿到一组物理一致的初值,随后进入紧耦合滑动窗口非线性优化(IMU 预积分残差 + 视觉重投影残差 + 边缘化先验),持续联合估计位姿、速度、零偏与路标点。加速度计零偏 $b_a$ 也在此阶段开始被优化收敛。

总结

VINS-Mono 的初始化把一个高度非线性、强耦合的问题,巧妙拆解为一串近似线性的子问题,逐个稳定求解:

步骤求解对象方法
① SfM无尺度相对位姿 + 路标对极几何 / PnP / 视觉 BA
② 预积分IMU 运动增量解析积分 + 雅可比
③ 陀螺标定$b_g$$3\times3$ 线性最小二乘
④ 线性对齐$v_k,\ g^{c_0},\ s$大型线性最小二乘
⑤ 重力细化$g$ 方向切平面 2-DoF 迭代
⑥ 对齐世界系带尺度真实轨迹旋转 + 缩放

三个要点:

解耦 预积分让 IMU 约束与绝对位姿无关,使线性化成为可能。

重力即标尺 已知重力模长是单目尺度可观测的根本来源。

充分激励 初始化需要足够的平移运动,纯旋转或静止会导致尺度/速度不可观测而失败。
