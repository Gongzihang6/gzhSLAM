# ORB-SLAM：视觉里程计的核心演进与全流程解析

ORB-SLAM系列是视觉SLAM（同步定位与建图）领域最经典、最著名的开源框架之一。其核心设计思想围绕着**特征点提取、多线程架构、基于图的非线性优化（Bundle Adjustment, BA）以及词袋模型（Bag-of-Words）**展开。从最初的单目版本发展到支持多传感器的 ORB-SLAM3，该系列在静态环境下的精度和鲁棒性一直处于业界标杆地位。
一、 ORB-SLAM 系列的核心原理

1. 基于 ORB 特征的稀疏表达 系统摒弃了容易受光照和运动模糊影响的直接法，选择在前端提取 ORB (Oriented FAST and Rotated BRIEF) 特征点。ORB 特征对旋转和尺度具有鲁棒性，对相机的自动曝光和光照变化有良好的不变性，且提取和匹配速度极快，能够满足实时性要求
。整个系统在预处理后丢弃原始图像，所有的跟踪、建图和重定位任务均基于这些特征点完成
。
2. 统一的高效场景识别（DBoW2 词袋模型） ORB-SLAM 引入了基于 DBoW2 的词袋模型用于场景识别
。无论是应对视觉跟踪丢失时的相机重定位（Relocalization），还是为了消除累积误差的回环检测（Loop Closing），甚至是在 ORB-SLAM3 中的多地图融合（Map Merging），均依赖该词袋模型来提供长期数据关联（Long-term data association）
。
3. 共视图（Covisibility Graph）与生成树（Spanning Tree）结构 为了在大规模场景中保持恒定的计算复杂度，ORB-SLAM 构建了共视图（连接观察到相同 3D 地图点的关键帧）和最小生成树
。这使得跟踪和局部建图模块可以只在当前帧所在的“局部窗口”内进行运算，而不受全局地图大小的拖累
。
4. 多层级的非线性优化（Bundle Adjustment） 系统完全建立在最大后验概率（MAP）估计的基础之上，在不同阶段使用不同规模的 BA 优化：
Motion-only BA（仅运动优化）：仅优化当前帧的相机位姿，地图点固定
。
Local BA（局部优化）：优化当前关键帧、共视关键帧及其观测到的局部地图点
。
Full BA（全局优化）：在检测到回环后，对全局所有的关键帧和地图点进行极致优化，以消除累积漂移
。
二、 ORB-SLAM 系列的演进与差异
ORB-SLAM2： 扩展了对双目（Stereo）和 RGB-D 相机的支持
。单目 SLAM 存在尺度漂移和初始化困难的问题，ORB-SLAM2 利用双目和深度信息直接恢复真实的物理尺度（Metric Scale），实现了零漂移的重定位，并支持一个“仅定位模式（Lightweight localization mode）”，在已建好的地图中关闭建图功能以节省算力
。
ORB-SLAM3： 在 2 代基础上实现了两大突破。一是引入了紧耦合的视觉-惯性（Visual-Inertial）SLAM，通过 MAP 估计实现了极快的 IMU 初始化，大幅提升了在无纹理或快速运动时的鲁棒性
。二是提出了 Atlas 多地图系统，在系统跟丢时能够自动创建新地图，并在重新回到已知区域时无缝拼接历史地图（多会话 SLAM）
。此外，它还抽象了相机模型，支持鱼眼相机（Fisheye）等更多模型
。
三、 ORB-SLAM 的完整工作流程（Pipeline）
以目前最完善的 ORB-SLAM2/3 架构为例，其完整流程由并行的四个主要线程构成：
第一步：跟踪线程 (Tracking Thread)
这是最高频的线程，负责实时处理传感器输入并计算相机的当前位姿。
输入预处理与特征提取：对于双目或 RGB-D，提取左图或彩色图的 ORB 特征。利用深度信息或右图匹配合成出特征点的 3D 虚拟坐标（划分为“近点”和“远点”）
。对于 IMU，则在此阶段进行预积分
。
初始位姿估计：利用恒速运动模型预测当前帧的位姿。如果跟踪丢失，则调用 DBoW2 词袋库在全局地图中进行重定位
。
局部地图跟踪（Track Local Map）：将局部地图中的 3D 点投影到当前帧的图像平面，寻找匹配点，并执行 Motion-only BA 最小化重投影误差，从而得到极其精准的当前位姿
。
关键帧决策：判断当前帧是否包含足够多的新信息（如观测到了新的闭塞区域、特征点数量变化等）。如果是，则将其作为“关键帧（KeyFrame）”传递给局部建图线程
。
第二步：局部建图线程 (Local Mapping Thread)
该线程负责维护和优化局部地图，是保证前端精度的关键。
关键帧插入：将新的关键帧加入共视图，更新生成树，并计算该帧的词袋向量
。
地图点筛选与生成：剔除冗余的、质量差的 3D 地图点（Culling）。同时，将当前关键帧与共视关键帧中未匹配的 2D ORB 特征进行三角化，生成新的 3D 地图点
。
局部光束法平差 (Local BA)：取当前关键帧及其在共视图中的邻居关键帧，联合它们观测到的所有 3D 点，进行 Local BA 优化。不在该局部窗口但观测到这些点的历史关键帧提供约束但不参与优化
。
关键帧剔除 (Local KeyFrames Culling)：如果某个关键帧的 90% 以上的地图点都能被其他至少三个关键帧观测到，该关键帧会被视为“冗余”并被剔除，从而控制地图规模
。(注：在 ORB-SLAM3 中，此线程还负责 IMU 参数的快速初始化和尺度细化)
。
第三步：回环检测与地图融合线程 (Loop Closing & Map Merging Thread)
该线程以关键帧的频率运行，用于消除全局累积漂移。
位置识别 (Place Recognition)：对于每一个新关键帧，通过 DBoW2 查询数据库中相似的历史关键帧。ORB-SLAM3 引入了高召回率策略，先进行几何一致性校验，再利用共视关键帧进行局部一致性校验
。
计算相似变换：在单目中计算 Sim(3) 变换（包含尺度），在双目/RGB-D 中计算 SE(3) 刚体变换，以对齐当前关键帧与匹配到的历史关键帧
。
回环融合 (Loop Fusion) 或 地图合并 (Map Merging)：
如果是同一个地图（回环）：将回环两侧的地图点进行对齐，剔除重复的地图点，并在共视图中增加新的边
。
如果是不同地图（Atlas 地图合并，仅限 v3）：将当前活动地图（Active Map）与旧地图无缝焊接到一起（Welding BA），合并为一个新的活动地图
。
位姿图优化 (Pose-Graph Optimization)：为了将回环处的误差修正均匀地分摊到整个轨迹中，算法会沿着本质图（Essential Graph）执行位姿图优化
。
第四步：全局优化线程 (Full BA Thread)
为了不阻塞前端的实时运行，这个线程仅在回环检测或地图融合执行完毕后，作为独立的第四个线程被异步唤醒
。
全局光束法平差 (Full BA)：对地图中所有的关键帧位姿和所有的 3D 地图点执行一次彻底的全局非线性优化，计算出最优的结构与运动（Structure and Motion）解
。
地图更新：如果在 Full BA 运行期间，前端又生成了新的关键帧，系统会通过生成树将 Full BA 的优化差值（Correction）传播给这些未参与优化的新关键帧，完成地图的无缝同步
。
