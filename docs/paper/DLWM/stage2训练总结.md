# stage2 训练总结

## 一、总体架构概述

本阶段为阶段2的训练框架，顶层模块为BEVWorldModelPredictor，主要由以下5个核心模块组成：

| 模块               | 类型                         | stage2状态 | 作用                                   |
| ------------------ | ---------------------------- | ---------- | -------------------------------------- |
| Image Backbone     | HENet-TinyM                  | 冻结       | 多视角相机图像特征提取                 |
| Image Neck         | Splat2BEVFPN                 | 冻结       | 多尺度特征融合                         |
| GaussianLifter     | GaussianLifter               | 微调       | 预测深度分布，将2D图像特征Lift到3D空间 |
| VolumeConstruction | VolumeConstruction(LSS)      | 训练       | 将Lift后的特征splat到BEV空间           |
| BEV World Model    | BEV World Model(Transofrmer) | 训练       | 基于历史帧BEV自回归预测未来帧          |
