# 紧耦合的原理与优点

广义上，只要我们设计的状态估计系统考虑了 **各传感器内在的性质**，而非 **模块化的将它们的输出进行融合**，就可以称为紧耦合 LIO 系统。

例如，考虑了 IMU 观察噪声和零偏的系统，就可以称为 IMU（或 INS）的紧耦合；考虑了激光雷达点云的配准残差，就可以称为激光的紧耦合；考虑了视觉特征点的重投影误差，或者考虑了 RTK 的细分状态、搜星数等信息，就可以称为视觉或者 RTK 的紧耦合。

而在松耦合 LIO 系统中，可以单纯的将各传感器或算法模块看作黑箱，只考虑它们的输出。紧耦合系统，将各传感器内在的误差糅合在一起，更稳定。

在实际情况中，如果各算法模块都在正常工作，那么紧耦合 LIO 系统与松耦合 LIO 系统可能并没有明显差异。但是在实际系统中，单个算法模块往往并不能一直保持正常工作。单独的 IMU 系统，若没有速度和位置方面的观测，是会很快发散的；单独的雷达里程计和视觉里程计，在场景结构不良的场合，也会出现丢失、退化的问题。

在松耦合LIO系统中，如果一个模块失效，就必须在逻辑上识别出它的失效，再想办法将他恢复成正常状态，否则，一个模块的不良输出，就会直接对最终结果产生很大影响，带偏整个系统。而在紧耦合LIO系统里，一个模块的工作状态能够直接反应到另一个模块中，帮助它们更好的约束自身的工作维度。
